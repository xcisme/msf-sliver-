## 关键约定

1. **路由前缀**：所有 API 以 `/api/` 开头
2. **认证**：需要认证的接口使用 `current_user: User = Depends(get_user)`
3. **数据库**：通过 `db: Session = Depends(get_db)` 获取会话
4. **日志记录**：关键操作调用 `add_log()` 写入 `operation_logs` 表
5. **错误处理**：使用 `HTTPException` 返回标准错误响应
6. **响应模型**：使用 `response_model` 声明返回类型
7. **中文注释**：docstring 使用中文
8. **配置读取**：通过 `from app.core.config import settings` 读取配置
9. **MSF 客户端**：每次请求创建新的 `MsfClient` 实例（无连接池）
10. **Sliver 客户端**：待实现，应遵循与 MsfClient 类似的封装模式
